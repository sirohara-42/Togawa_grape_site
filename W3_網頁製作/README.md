# 豐川葡萄 (Feng Chuan Grape) 官方品牌網站

> **品牌標語：** 好果成禮，心意豐盛。  
> **定位：** 專為企業贈禮、商務拜訪與精緻生活打造的台灣頂級水果禮盒品牌。

---

## 專案結構與工作目錄

```text

├── assets/

└── README.md               # 專案設計與部署說明文件
```

## 核心設計亮點與技術實現

### 1. 語意化 HTML (Semantic HTML5)
- 使用 `<header>`、`<nav>`、`<main>`、`<section>`、`<article>`、`<figure>`、`<figcaption>`、`<aside>`、`<footer>`、`<form>` 等語意標籤。
- 完整包含各規劃區塊：
  1. **Header & Navigation**：品牌 Logo、桌面多階選單、CTA 按鈕、深色模式切換鍵、手機版漢堡按鈕。
  2. **Hero 首屏**：「好果成禮，心意豐盛。」主視覺、雙 CTA 按鈕、關鍵品質指標橫條、漂浮職人引言卡。
  3. **品牌故事與理念 (自我介紹)**：彰化大村產地故事、友善農耕與極致甜度理念。
  4. **核心價值 (四大特色)**：精選好果、精緻包裝、客製化服務、地方特色。
  5. **專業工藝與技能展示**：光波糖度檢測技術 (99.5%)、恆溫冷鏈保鮮 (2-4°C)、專利包裝結構、企業 VIP 禮賓顧問。
  6. **精選禮盒系列**：四大經典產品卡片，支援分類標籤篩選與「快速查看 / 了解更多」彈窗。
  7. **服務流程情境**：四步驟客製流程展示（諮詢、提案、精工、冷鏈）。
  8. **FAQ 常見問題**：可展開收合之互動手風琴，並符合 ARIA 無障礙屬性。
  9. **客製洽詢表單 (主要 CTA)**：包含姓名、電話、Email、用途、預算、數量、配送日、客製備註與隱私同意。
  10. **Footer 頁尾**：品牌理念、快速導覽、熱門推薦、詳細聯絡資訊、社群圖標與合法登錄資訊。

### 2. 精品級 CSS 樣式與架構
- **視覺風格：** 現代極簡、精品質感、自然優雅。
- **精品配色：**
  - **葡萄深紫** (`#2A162B`, `--color-primary`)
  - **奶油白** (`#FAF8F5`, `--color-bg`)
  - **暖灰色** (`#706E6B`, `--color-text-muted` / `#E6E1D8`, `--color-border`)
  - **低彩度自然綠** (`#4E6554`, `--color-accent-green`)
  - **香檳金貴賓點綴** (`#C6A675`, `--color-accent-gold`)
- **Box Model 精確控制：**
  - 全站落實 `*, *::before, *::after { box-sizing: border-box; }`。
  - 每個元件（卡片、按鈕、輸入框）皆精細規劃 `margin`、`padding`、`border`，維持舒適的空間留白與呼吸感。
- **Positioning 定位技術運用：**
  - `position: sticky`：導覽列平滑置頂並於滾動時模糊半透明、縮小高度與投影。
  - `position: fixed`：行動版抽屜導覽、回到頂部按鈕、快速查看彈窗遮罩、即時 Toast 通知容器。
  - `position: relative` & `position: absolute`：裝飾性徽章、浮動引言卡、手風琴展開旋轉圖標、表單自訂 Checkbox、彈窗關閉按鈕。
- **響應式斷點 (RWD)：**
  - 手機版 (`≤ 640px`)：單欄排版、全寬觸控按鈕、側邊滑出抽屜導覽。
  - 平板版 (`641px ~ 992px`)：雙欄流暢網格。
  - 桌面版 (`≥ 993px`)：四欄精緻展示、高解析多圖堆疊排版。

### 3. JavaScript 互動與深色模式
- **深色模式切換 (Dark Mode)：**
  - 支援手動切換與 `localStorage` 偏好記憶。
  - 自動偵測系統 `prefers-color-scheme: dark`。
  - 太陽/月亮圖示旋轉縮放過渡動畫。
  - 精心配比深色主題調色盤（暗沉夜幕紫背景搭配香檳金標題），不傷眼且保有貴族奢華感。
- **行動版導覽抽屜 (Mobile Drawer)：**
  - 平滑滑入與半透明模糊遮罩。
  - 支援點擊遮罩關閉、按 Esc 關閉與選中連結後自動關閉。
- **常見問題手風琴 (FAQ Accordion)：**
  - 點擊展開時平滑計算高度動畫 (`scrollHeight`)，收合其他項目，維持畫面清爽。
- **禮盒分類與詳細彈窗 (Quick View Modal)：**
  - 依品類即時過濾商品卡片。
  - 彈窗展示糖度、保存方式、產地履歷與客製優勢。
  - 點擊「洽詢此款禮盒」自動帶入下方表單下拉選單並滑動至表單區。
- **客製表單即時驗證與 Toast 提示：**
  - 即時驗證台灣手機號碼格式、Email 格式與必填項目。
  - 送出時按鈕動態呈現載入旋轉動畫 (Spinner)，並於送出後彈出優雅的 Toast 通知並自動重設表單。

## 本地預覽與部署指引

### 1. 本地啟動預覽 (Local Server)
任何支援靜態網頁的 HTTP 伺服器均可直接執行本專案：

```bash
# 使用 Python 內建 HTTP Server
python3 -m http.server 8080

# 或使用 Node.js http-server / npx serve
npx serve .
```
開啟瀏覽器前往 `http://localhost:8080` 即可預覽完整功能。

### 2. 靜態網頁平台一鍵部署 (Deployment)
本專案為零依賴純前端架構 (Pure HTML/CSS/JS)，可直接上傳至：
- **GitHub Pages**：將程式碼推送至 GitHub 儲存庫，在 Settings -> Pages 選擇 `main` 分支根目錄即可自動發佈。
- **Vercel / Netlify / Cloudflare Pages**：直接拖曳資料夾或連接 Git 儲存庫即可完成秒級全球 CDN 部署。
